# Python Programming Course - LAB University of Applied Sciences

## Overview

This repository contains Python practice files and assignments for the Programming course at LAB University of Applied Sciences. It is organized by weekly tasks and includes examples, exercises, and data files used during the semester.

## Structure

- `Week 1/` through `Week 10/` — Weekly exercises and task files.
- `Extra Paractice/` — Additional practice programs, real-world problems, and revision material.
- `*.txt`, `*.csv` — Data files, exercise outputs, and assignment references.
- `README.md` — This overview document.

## Weekly Folder Guide

Each `Week X/` folder typically includes:
- `Task1.py` through `Task7.py` — Main weekly exercises.
- `cheatsheet.py` or helper files — Notes and supporting scripts.

## Key Contents

- `Week 1/` to `Week 10/` contain task-based Python programs that cover:
  - basic syntax and control flow
  - functions and modules
  - file handling and data processing
  - loops, conditionals, and lists
  - real-world problem solving
- `Extra Paractice/` contains additional examples such as:
  - class practice
  - loops and functions
  - matplotlib and turtle practice
  - pandas practice problems

## How to Use

1. Open the folder in Visual Studio Code or any Python editor.
2. Browse the week folder that matches the course schedule.
3. Run the task file using Python, for example:
   ```bash
   python "Week 1/Task1.py"
   ```
4. Explore the `Extra Paractice/` folder for supplemental practice.

## Notes

- File names are mostly organized by week and task number.
- Some practice folders include additional files for libraries and helpers.
- If you want to add more content, keep the same `Week X/TaskY.py` naming convention.
